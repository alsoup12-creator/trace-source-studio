API 与 MCP

本地文件溯源无需 AI 或 API 即可运行；其他接口只在需要联网检索、法规检索或来源理解时调用。

网页搜索源

搜索接口负责找候选；启用理解层后，问答接口负责生成检索问题。候选的“深读此来源”按次调用问答接口，概括必须绑定来源原文。

北大法宝 MCP

默认在请求中限定“现行有效”，并过滤明确标注为失效或废止的结果；效力字段缺失的候选会标注“效力待核验”。返回结果只作为候选，不自动判断适用性。

本地模型（可选智能细分与检索辅助）

“本地 AI 智能细分”只让模型组合程序预切的编号片段，原文由程序重建并校验；适合测试4B及以下指令模型。溯源时若勾选本地 AI 补充检索，模型还会在强匹配不足时扩展短检索词。文件读取、原文定位和候选对齐始终由规则完成。
